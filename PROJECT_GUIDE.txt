1. PROJECT OVERVIEW
================================================================================

SmartInventory is a full-stack instrument inventory management system built for
small-to-medium businesses that sell or rent physical instruments/equipment.

Core capabilities:
  - Product catalogue management (add, edit, delete products)
  - Serial number tracking per unit (available / sold / damaged)
  - Stock In: receive inventory with serial numbers
  - Stock Out: dispatch units to customers with serial numbers
  - Full audit history of all stock movements
  - Role-based access: ADMIN and STAFF
  - JWT-based authentication
  - Live database viewer (ADMIN only)

The backend is a Spring Boot REST API.
The frontend is plain HTML + CSS + Vanilla JS (no build step needed).
The frontend is served as static files by Spring Boot itself - ONE JAR file.

6. LOCAL DEVELOPMENT SETUP (STEP-BY-STEP)
================================================================================

STEP 1: Clone the repository
  git clone https://github.com/YOUR_USERNAME/smartinventory.git
  cd smartinventory

STEP 2: Create a local MySQL database
  mysql -u root -p
  CREATE DATABASE smartinventory CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
  CREATE USER 'inv_user'@'localhost' IDENTIFIED BY 'yourpassword';
  GRANT ALL PRIVILEGES ON smartinventory.* TO 'inv_user'@'localhost';
  FLUSH PRIVILEGES;
  EXIT;

STEP 3: Set environment variables (Windows PowerShell)
  $env:SPRING_DATASOURCE_URL = "jdbc:mysql://localhost:3306/smartinventory?useSSL=false&serverTimezone=UTC"
  $env:SPRING_DATASOURCE_USERNAME = "inv_user"
  $env:SPRING_DATASOURCE_PASSWORD = "yourpassword"
  $env:JWT_SECRET = "dGhpcy1pcy1hLXN0cm9uZy10ZXN0LXNlY3JldC1mb3ItZGV2"
  $env:JWT_EXPIRATION_MS = "86400000"
  $env:ALLOWED_ORIGINS = "http://localhost:8080"
  $env:APP_BOOTSTRAP_ADMIN_USERNAME = "admin"
  $env:APP_BOOTSTRAP_ADMIN_PASSWORD = "Admin@12345678"

  (Linux/macOS bash - use export instead of $env:)
  export SPRING_DATASOURCE_URL="jdbc:mysql://localhost:3306/smartinventory?useSSL=false&serverTimezone=UTC"
  export SPRING_DATASOURCE_USERNAME="inv_user"
  export SPRING_DATASOURCE_PASSWORD="yourpassword"
  export JWT_SECRET="dGhpcy1pcy1hLXN0cm9uZy10ZXN0LXNlY3JldC1mb3ItZGV2"
  export JWT_EXPIRATION_MS="86400000"
  export ALLOWED_ORIGINS="http://localhost:8080"
  export APP_BOOTSTRAP_ADMIN_USERNAME="admin"
  export APP_BOOTSTRAP_ADMIN_PASSWORD="Admin@12345678"

STEP 4: Build and run
  ./mvnw spring-boot:run
  (Windows: mvnw.cmd spring-boot:run)

STEP 5: Open in browser
  http://localhost:8080
  Login: admin / Admin@12345678

STEP 6: Remove bootstrap vars after first login

9. BACKEND API ENDPOINTS
================================================================================

  All endpoints require: Authorization: Bearer <JWT_TOKEN>
  (except /auth/login)

  AUTH
    POST  /api/auth/login       Body: {username, password} -> {token, username, role}
    POST  /api/auth/register    Body: {username, password, role}  [ADMIN only]

  PRODUCTS
    GET   /api/products         List all products
    GET   /api/products/{id}    Get one product
    POST  /api/products         Create product  [ADMIN]
    PUT   /api/products/{id}    Update product  [ADMIN]
    DELETE /api/products/{id}   Delete product  [ADMIN]

  SERIAL NUMBERS
    GET   /api/serial-numbers                            All serials
    GET   /api/serial-numbers/product/{pid}              By product
    GET   /api/serial-numbers/product/{pid}/status/{s}  By product + status
    POST  /api/serial-numbers/product/{pid}              Add serial
    PATCH /api/serial-numbers/{id}/status               Update status
    DELETE /api/serial-numbers/{id}                      Delete serial

  STOCK
    POST  /api/stock-in   Body: {productId, serialNumbers:[], referenceNote}
    POST  /api/stock-out  Body: {productId, serialNumbers:[], referenceNote}

  INVENTORY
    GET   /api/inventory            All products stock levels
    GET   /api/inventory/{pid}      One product stock level

  HISTORY
    GET   /api/history              All transactions (?type=IN&from=date&to=date)
    GET   /api/history/{id}         Transaction with items

  HEALTH
    GET   /actuator/health          Returns {"status":"UP"}

    - View + manage serial numbers

    - View inventory and history

11. FIRST-TIME ADMIN BOOTSTRAP
================================================================================

  No default accounts ship with the application.

  On first deployment with empty users table:
    Set APP_BOOTSTRAP_ADMIN_USERNAME and APP_BOOTSTRAP_ADMIN_PASSWORD
    The app creates one BCrypt-hashed admin account automatically.
    After first login - REMOVE these two env variables immediately.

  The bootstrap only triggers when the users table is completely empty.
  It will never overwrite existing accounts.

12. DEPLOYING TO RENDER.COM (STEP-BY-STEP)
================================================================================

  STEP 1: Push code to GitHub
    git add . && git commit -m "deploy" && git push origin main

  STEP 2: Get a free MySQL database
    Option A: PlanetScale  -> planetscale.com  (free, no credit card)
    Option B: Aiven        -> aiven.io         (free tier)
    Option C: TiDB Cloud   -> tidbcloud.com    (free tier)

    Get the JDBC connection string:
      jdbc:mysql://HOST:PORT/DBNAME?useSSL=true&requireSSL=true

  STEP 3: Create Web Service on Render
    render.com -> Dashboard -> New -> Web Service
    -> Connect GitHub repo
    -> Render auto-detects Dockerfile
    Settings:
      Name:          smartinventory
      Region:        Choose nearest (Singapore for India)
      Branch:        main
      Runtime:       Docker
      Instance Type: Free (or Starter $7/mo for always-on)

  STEP 4: Add Environment Variables on Render
    Service -> Environment -> Add each variable:

      SPRING_DATASOURCE_URL       jdbc:mysql://HOST:PORT/DB?useSSL=true&requireSSL=true
      SPRING_DATASOURCE_USERNAME  your_db_user
      SPRING_DATASOURCE_PASSWORD  your_db_password
      JWT_SECRET                  (run: openssl rand -base64 32)
      JWT_EXPIRATION_MS           86400000
      ALLOWED_ORIGINS             https://YOUR-APP.onrender.com
      APP_BOOTSTRAP_ADMIN_USERNAME  admin
      APP_BOOTSTRAP_ADMIN_PASSWORD  StrongPassword123!

  STEP 5: Click Deploy
    Build takes 3-5 minutes. Watch logs in Service -> Logs.

  STEP 6: Visit your app
    https://YOUR-APP.onrender.com
    Login with the bootstrap credentials.

  STEP 7: Remove bootstrap variables (CRITICAL!)
    Service -> Environment -> Delete:
      APP_BOOTSTRAP_ADMIN_USERNAME
      APP_BOOTSTRAP_ADMIN_PASSWORD
    Save -> Render redeploys automatically.

  IMPORTANT RENDER NOTES:
    - Free tier sleeps after 15 min inactivity (cold start ~30 sec)
    - Upgrade to Starter ($7/mo) for always-on
    - Health check endpoint: /actuator/health
    - Build logs: Service -> Logs

14. COMMON ERRORS AND FIXES
================================================================================

  ERROR: Communications link failure
  FIX:   Check SPRING_DATASOURCE_URL is correct. MySQL must be accessible.
         Local: ensure MySQL service is running.

  ERROR: Table does not exist
  FIX:   Flyway migration failed. Check DB user has CREATE privilege.
         Check Logs for Flyway errors.

  ERROR: Schema-validation: missing column
  FIX:   DB schema is out of sync. Flyway migration needs to run.
         Ensure spring.flyway.enabled=true in application.properties.

  ERROR: 401 Unauthorized on all API calls
  FIX:   JWT expired. Log out and log in again.
         Increase JWT_EXPIRATION_MS (86400000 = 24 hours).

  ERROR: CORS error in browser
  FIX:   Set ALLOWED_ORIGINS to your exact frontend URL (no trailing slash).
         ALLOWED_ORIGINS=https://smartinventory.onrender.com

  ERROR: Invalid credentials on login
  FIX:   Bootstrap admin not created. Set APP_BOOTSTRAP_ADMIN_* vars,
         ensure users table is empty, restart app.

  ERROR: Port already in use (local)
  FIX:   netstat -ano | findstr :8080  then  taskkill /PID <pid> /F
         Or use a different PORT env variable.

  ERROR: Build fails - Tests failed
  FIX:   Quick fix: ./mvnw clean package -DskipTests
         Proper fix: run ./mvnw test to see what is failing and fix it.

15. DATABASE NOTES
================================================================================

  Flyway manages all schema changes. Do NOT manually alter production tables.

  To add a column or table:
    Create: src/main/resources/db/migration/V2__your_description.sql
    Flyway runs it automatically on next startup.

  Backup before any change:
    mysqldump -u USER -p DBNAME > backup_20261019.sql

  Test/seed data files (LOCAL ONLY - do not run on production):
    sample_data.sql    - demo data for local testing
    tidb_seed.sql      - TiDB-compatible seed data

  Legacy files (DO NOT RUN on production - they DROP tables):
    fix_tables.sql
    rebuild_db.sql
    setup_database.sql

  Minimum DB user permissions for the app:
    GRANT SELECT, INSERT, UPDATE, DELETE, CREATE, ALTER, INDEX
    ON smartinventory.* TO 'inv_user'@'%';
