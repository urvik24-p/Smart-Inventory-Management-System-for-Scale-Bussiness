SmartInventory database information
===================================

The authoritative database documentation and ER diagram are in DATABASE.md.

Production schema source
------------------------
Use Flyway migrations stored in:
  src/main/resources/db/migration

Do not use setup_database.sql, rebuild_db.sql, or fix_tables.sql in production.
Those legacy files contain destructive DROP statements and are retained only for local, disposable development databases.

Required deployment variables
-----------------------------
SPRING_DATASOURCE_URL
SPRING_DATASOURCE_USERNAME
SPRING_DATASOURCE_PASSWORD
JWT_SECRET
ALLOWED_ORIGINS

See .env.example for names and safe example formats. Never commit actual passwords, database URLs with credentials, or JWT keys.

Core tables
-----------
products                Catalogue record for an inventory item.
serial_numbers          One physical unit; globally unique serial and live status.
stock_transactions      Immutable IN/OUT inventory movement header.
stock_transaction_items Physical units included in a transaction.
users                   Login identity, BCrypt password hash, and role.

Data integrity rules
--------------------
* A product owns zero or more serial numbers.
* A serial belongs to exactly one product.
* A transaction owns one or more transaction items.
* Every transaction item references one transaction, product, and serial number.
* Sold serials are never deleted or manually restored.
* Products with serial history cannot be deleted.
